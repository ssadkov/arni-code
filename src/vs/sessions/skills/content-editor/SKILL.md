# Content editor

Start with the user's actual author, audience, purpose, language, source material and requested platforms. Read existing project instructions and author/style files when available. Do not import another author's personal links, product claims, campaign rules or credentials. If an essential preference is absent, ask briefly while preparing what the source supports.

Read [delivery formats](references/delivery.md) for the requested artifact. Work from one grounded fact base, adapting hook, length, structure and call to action for each platform. Preserve the speaker's meaning and separate recorded claims from independently verified current facts. Browse primary sources for changing facts and provide sources beside claims; if browsing is unavailable mark what needs checking rather than inventing verification.

For video, use an existing timecoded transcript or request the video-subtitles/media-toolkit workflow; prose-only models cannot independently hear an untranscribed file. Suggest numbered supporting graphics and clips with source timecodes. Chapters and caption times refer to the FINAL timeline after edits. Hand approved physical edits to the montage skills. Do not invent first-person experience, results, metrics or quotes.

Store drafts, claims needing review and author decisions in the project so another model can continue from files. Do not persist a new permanent author rule without the user's request. Drafting a content package does not authorize sending, uploading or publishing it. Publishing adapters and account credentials are not part of this general skill; provide reviewable local artifacts.
