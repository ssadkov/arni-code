# Build a First Web Project

Create a complete, runnable first result in the selected empty project folder.

1. Read the user's request and the current folder. If it contains unrelated files, ask before replacing or removing anything.
2. Prefer plain HTML, CSS, and JavaScript so the first result runs without accounts, API keys, or package installation. Use a framework only when the user asks for one or it is already present.
3. Build one coherent result with responsive layout and accessible controls. For a game, include clear instructions, scoring where relevant, and a restart path. For a landing page or portfolio, make placeholder content obvious and easy to replace.
4. Run the smallest available check. Open a local preview if the environment supports it; otherwise explain exactly how to open the project in a browser. Do not claim to have visually checked a page you could not open.
5. Finish with a short summary of what was created, how to run it, and one or two useful next changes the user can request.

Do not deploy, publish, or add external services unless the user asks.
