# ArniCode Brand Kit

Финальные версии логотипа ArniCode в выбранной стилистике.

## Знак

- `arnicode-ac-original-style-512.png` — цветной знак, прозрачный фон, 512×512.
- `arnicode-ac-dark-512.png` — знак на тёмном фоне, 512×512.

## Горизонтальный логотип

- `arnicode-horizontal-transparent-opaque.png` — прозрачный фон, 1400×500.
- `arnicode-logo-dark-1200x500.png` — тёмный фон, 1200×500.

## Квадратный логотип

- `arnicode-square-transparent-1024.png` — знак сверху, подпись снизу, прозрачный фон.
- `arnicode-square-dark-1024.png` — знак сверху, подпись снизу, тёмный фон.

Название пишется без пробела: **ArniCode**.
