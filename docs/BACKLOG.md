# Arni Code — Бэклог разработки

В этом документе зафиксированы приоритетные задачи и фичи для будущих версий IDE **Arni Code** от компании **Arnion**.

## 1. Авторизация и профили пользователей (High Priority)

### 1.1. Интеграция VK ID (`vk-authentication`)
- **Цель**: Предоставить российским разработчикам возможность быстрого входа в IDE через единую экосистему VK ID.
- **Требования**:
  - Создание и публикация OAuth 2.0 / OpenID Connect приложения в панели [VK ID для разработчиков](https://id.vk.com/about/business/go/).
  - Разработка встроенного расширения `extensions/vk-authentication`, регистрирующего провайдера аутентификации `vk` через VS Code Authentication API (`vscode.authentication.registerAuthenticationProvider`).
  - Поддержка входа через локальный HTTP loopback сервер (`http://127.0.0.1:<port>`) и перехват системного протокола `arni-code://auth/vk`.
  - Безопасное хранение Access Token и Refresh Token в Windows Credential Manager (`SecretStorage`).
  - Отображение аватара и имени пользователя VK в нижнем статус-баре и меню аккаунтов.

### 1.2. Интеграция Яндекс ID (`yandex-authentication`) — ✅ РЕАЛИЗОВАНО (v1.0.0)
- **Статус**: Встроено в кодовую базу как нативное расширение `extensions/yandex-authentication/`.
- **Реализовано**:
  - Провайдер `yandex` через VS Code Authentication API (`vscode.authentication.registerAuthenticationProvider`).
  - Локальный HTTP loopback сервер (`http://127.0.0.1:<port>/callback`) с защитой от CSRF (`state`) и поддержкой стандарта PKCE (S256).
  - Интеграция кнопки «Войти через Яндекс ID» в мастер первого запуска (Onboarding Wizard).
  - Запрос профиля через API `https://login.yandex.ru/info` и сохранение сессии в безопасном хранилище `SecretStorage` (Windows Credential Manager).
  - Добавлена настройка `yandex.clientId` и `yandex.clientSecret` для подключения корпоративного приложения Яндекс OAuth.

### 1.3. Прямой Google OAuth 2.0 (`google-authentication`)
- **Цель**: Автономный вход через Google без промежуточного перенаправления через GitHub Social Auth.
- **Требования**:
  - Регистрация десктопного OAuth Client ID в Google Cloud Console.
  - Встроенный OAuth loopback listener для обработки редиректа от Google Accounts.
  - Реализация провайдера `google` в VS Code Authentication API.

## 1.5. Первый экран для новичка (ревью 2026-09-25)

Цель — «русский Cursor»: человек без опыта открывает Arni и за минуту получает работающий результат. Экран проверялся на чистом профиле через CDP.

### Сделано (2026-09-26)
- **Один вход.** Пока у пользователя меньше двух сеансов, домашний экран — только галерея «Что создадим?»: поле «опишите идею своими словами» и готовые идеи. Клик по идее сразу создаёт папку (`snake-game`, `snake-game-2`…) в `~/Arni Projects` и запускает агента. Выбор папки, поле ввода и строка режимов скрыты. Ссылка «У меня уже есть папка с проектом» возвращает обычный экран и запоминается.
- **Крупный шрифт.** Галерея 15px, заголовок 26px, `chat.fontSize` по умолчанию 15 (было 13).
- **«Copilot» → «Arni»** в выборе агента (дескриптор agent host и подписи провайдера).
- **Окно входа.** Убран английский юридический текст про GitHub/Copilot: он показывается только когда в product.json есть свои `termsStatementUrl` и `privacyStatementUrl`. «Return to VS Code Editor» → «Вернуться в редактор».
- **Перевод строк первого экрана:** Сеансы, Новый, Автоматизации, Чаты, Настроить, Модели, режимы агента, «Подтверждать вручную», Изменения, Файлы. Плашка модели стала тихой подписью.

### Сделано (2026-09-26, второй заход)
- **Агент отвечает по-русски и реже спрашивает.** Роль агента в системном промпте (`COPILOT_AGENT_HOST_IDENTITY`) теперь — Arni: всегда по-русски, включая вопросы и варианты ответа; не задавать уточняющих вопросов, если можно сделать разумное допущение; объяснять результат простыми словами. На живой модели ещё не проверено.
- **Без подтверждений по умолчанию:** `chat.defaultConfiguration.approvals` = «Разрешить всё», `chat.permissions.default` = `autoApprove`.
- **«Новый проект» в сайдбаре** — строка под заголовком «Сеансы», открывает галерею в любой момент (команда `workbench.action.sessions.newProject`).
- **Сеансы Claude Code убраны:** `chat.agentHost.claudeAgent.enabled` по умолчанию `false`.
- **Правая панель скрыта по умолчанию** в новом сеансе и в раскладке окна. Если пользователь её однажды открыл, выбор запоминается.
- **Перевод чата:** «Готово, шагов: N», «Ждём вашего ответа…», кнопки вопросов («Отправить», «Свой ответ»), «Без папки», названия уровней разрешений и основных инструментов.

### Осталось
1. **Свои Условия и Политика конфиденциальности (блокер публичного запуска).** Сейчас в окне входа юридического текста нет вовсе. Проверить, как `:free`-модели OpenRouter обращаются с запросами (часть провайдеров логирует и обучается на них), и честно написать об этом.
2. **Проверить на живой модели**, что Nemotron слушается нового промпта: отвечает по-русски, не заваливает вопросами, доводит «Змейку» до работающего результата. Замерить время.
3. **`configurationDefaults` в product.json не читается на десктопе** — только веб-встраиванием (`workbench/services/configuration/browser/configuration.ts`). Значит `workbench.startupEditor`, `secondarySideBar.defaultVisibility`, `chat.defaultModel`, `chat.agentHost.*` оттуда не действуют (подтверждено по коду, в рантайме не проверено). Либо подключить чтение, либо перенести дефолты в регистрации настроек, как сделано для `chat.fontSize`.
4. **Риск «Разрешить всё» по умолчанию:** агент выполняет команды без вопросов в любой папке, не только в стартовой. Для новичка это правильно, но нужна понятная кнопка «остановить» и, возможно, песочница для терминала.
5. **Флаки-тест:** `CopilotAgent › provisional session anchors customization discovery to the additional roots` падает по таймауту 2 с примерно 1 раз из 6 прогонов (не связан с изменениями Arni).
6. **«Agent» в поле ввода** — имя встроенного режима `ChatMode.Agent`, оно же идентификатор. Нужен отдельный отображаемый label.
7. **Рыбка вверху слева** — upstream-пасхалка «аквариум» (`aquariumService.mountToggle` в `newChatWidget.ts`). Убрать из продукта.
8. **Перевод окна агентов целиком.** Официальный пакет оставляет строки `vs/sessions` английскими и в подсказках пишет «Copilot» (например, `agentHostPermissionPicker.*Hover`). Правило: русский текст по умолчанию в исходниках + то же значение в `extensions/vscode-language-pack-ru/translations/main.i18n.json`. Dev-сборка пакет не применяет, в релизе значение из пакета перекрывает исходник.
9. **Шрифт редактора.** `editor.fontSize` остался 14 (это `EDITOR_FONT_DEFAULTS`, задевает много тестов). Обсудить 15 или общий масштаб для новичков.
10. **Имя папки для своей идеи** сейчас `my-project`. Генерировать из текста идеи (транслит).
11. **Проверить вход на чистой машине** без `~/.arni-code-shared` и замерить время до первого результата.

## 3. Дистрибуция и инфраструктура

### 3.1. Цифровая подпись для Windows (Azure Trusted Signing) — High Priority
- **Цель**: Устранить предупреждения Windows SmartScreen («Система Windows защитила ваш компьютер») и UAC («Неизвестный издатель»), обеспечить бесшовную установку для пользователей.
- **Подробный гайд**: См. [WINDOWS_CODE_SIGNING.md](./WINDOWS_CODE_SIGNING.md).
- **План действий**:
  1. **Юридическая верификация (ТОО Казахстан)**:
     - Получение/проверка номера D-U-N-S на [dnb.com](https://www.dnb.com/) для казахстанского ТОО по БИН.
     - Проверка актуальности данных на корпоративном сайте (наименование, БИН, контакты) и доступности корпоративной почты/телефона.
  2. **Настройка Microsoft Azure**:
     - Создание подписки Azure на ТОО (оплата казахстанской бизнес-картой).
     - Создание ресурса `Trusted Signing Account` (~$9.99/мес) в регионе West Europe.
     - Прохождение проверки организации (`Identity Validation` -> `Organization`).
     - Создание профиля сертификата `Public Trust` (например, `ArniCode-PublicRelease`).
  3. **Интеграция в пайплайн сборки**:
     - Установка утилиты `Azure.CodeSigning.Dlib`.
     - Настройка скрипта `signtool.exe` с обязательным указанием RFC 3161 Timestamp (`http://timestamp.acs.microsoft.com`), чтобы подписанные версии оставались валидными бессрочно.
     - Интеграция вызова подписи в [`build/gulpfile.vscode.win32.ts`](../build/gulpfile.vscode.win32.ts) и [`build/azure-pipelines/common/sign-win32.ts`](../build/azure-pipelines/common/sign-win32.ts) для автоматической подписи `.exe`/`.dll` и итогового Inno Setup инсталлятора.

### 3.2. Автоматический выпуск релизов (CI/CD)

- Генерация хэш-сумм (SHA-256) для скачиваемых дистрибутивов.

### 3.3. Система автоматических обновлений
- Автоматическое фоновое обновление через Inno Setup background updater.
