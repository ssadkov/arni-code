# Надёжное заполнение форм: первый этап

18 октября 2026. Следующее обновление 1.0.10 включает карточку со своими полями из 1.0.9 и исправления ввода, повторов и ожидания подтверждения. Наличие правок в Git не означает, что приложение уже обновлено.

## Что показал тест AIFC

В установленной 1.0.8 бесплатная Nemotron VL не прочитала предоставленную страницу контактов и подставила вымышленные реквизиты. Вызовы ввода содержали только описание поля, без ref/селектора: текст шёл в текущий фокус, снимки не подтверждали заполнение. После этого агент семь раз пытался ввести Agree вопреки запросу на черновик. Пять запросов карточки истекли через 1800 секунд; параллельные операции задерживали продолжение до окончания ожидания. В журнале нет вызова отправки формы. Это не успешная регистрация и не доказательство непригодности всех бесплатных моделей.

## Изменения в коде

- Для текста `typeInPage` требует ref из снимка или точный селектор. `element` остаётся только подписью. Печатать текст в случайный фокус больше нельзя. Нажатия отдельных клавиш сохраняют прежнюю работу.
- Инструмент заполняет только редактируемый элемент, читает значение обратно и сравнивает с заданным. Обрезанное/нормализованное сайтом значение не считается успехом; источник ошибки объясняет необходимость осмотра страницы. Пустая строка позволяет явно очистить поле. Несвязанные поля не меняются.
- После двух одинаковых вызовов ввода без подтверждённого изменения третий блокируется. Счётчик относится к пользовательскому запросу и сбрасывается после реального изменения или нового сообщения. Повтор уже установленного значения не нажимает Enter повторно. Счётчики ограничены в памяти и не содержат исходного текста.
- Клиентские инструменты получают ID запроса. Встроенный инструмент может вернуть `stopCurrentTurn`: агент-хост фиксирует его результат и отменяет только соответствующий текущий turn. Внешние инструменты этим флагом отменять turn не могут. Это проверяется интеграционным тестом, а не только текстом инструкции модели.
- Просмотр/редактирование карточки сообщает об ожидании и через две минуты отменяет окно без выдачи или сохранения значений. Статусы `approval_timeout`, `awaiting_user`, `retry_blocked` останавливают turn; после отказа повторное окно в том же запросе не открывается. Новое сообщение пользователя позволяет начать новый просмотр. Позднее подтверждение истёкшего окна ничего не меняет.

## Изменения навыков

Секретарь должен прочитать вопросы формы, затем реальные источники значений, показать таблицу «поле → значение → источник», уточнить недостающее, заполнить и прочитать результат обратно. URL сам по себе не является прочитанным источником. Запрещено выводить компанию из названия проекта, придумывать БИН/контакты или заменять недоступную карточку примерами. Инструкции объясняют ref и запрет обходить остановку другим инструментом.

Это улучшение инструкций, не автоматическая проверка истинности каждого факта. Приложение пока не доказывает происхождение произвольного значения модели из веб-страницы.

## Граница первого этапа

Полного технического режима «Только черновик» ещё нет. В существующем наборе остаются клики, нажатия клавиш и выполнение браузерного кода; инструкции оставлять Agree/Submit нетронутыми не заменяют ограничение этих возможностей. Счётчик повторов контролирует последовательные одинаковые текстовые вызовы `typeInPage`, а не все возможные циклы агента. Для режима черновика требуется отдельная модель разрешённых действий на уровне сессии, охватывающая и универсальный браузерный код.

Реальная AIFC-форма в этой проверке не изменяется. Следующий ручной прогон: новая версия → новый чат Секретаря → бесплатная модель → чтение источника и проверяемый черновик; согласие и отправка остаются человеку. Сравнение с дешёвой платной моделью проводится отдельно после этого, с одинаковым заданием и учётом расходов.

## Проверки

- Целевые Electron-тесты карточки и клиентских инструментов: 74 проверки, включая служебную. Покрыты таймаут/отмена, запрет повторного окна, позднее подтверждение, изоляция аккаунтов, частичные изменения и порядок complete → cancel в agent-host.
- `scripts/test-browser-form-input.mjs` запускает настоящий headless Chromium и локальный HTTP-сервер с вымышленной формой. Проверяет потерянный фокус, точный ввод, очистку, textarea/contenteditable, нормализацию, maxlength, readonly, неподходящую цель, отмену, повторы и новое сообщение. 20 проверок ввода; согласие не выбирается, запросов отправки нет. Это тест инструмента, без модели и реальных персональных данных.

Запуск после транспиляции клиентских модулей:

```powershell
$env:VSCODE_SKIP_PRELAUNCH='1'
.\scripts\test.bat '--runGlob=**/{arniUserProfile,agentHostClientTools}.test.js'
node scripts/test-browser-form-input.mjs <путь-к-Chromium>
```

Путь к Chromium необязателен, если браузер Playwright уже установлен для текущей среды. Дополнительно прошли целевые проверки типов/синтаксиса, ESLint без предупреждений, официальный валидатор двух навыков, три проверки клиента библиотеки и SHA-256 всех 21 файлов экспортированного каталога. Платных вызовов моделей не было. Успешные тесты инструмента не доказывают, что конкретная модель уже выполнила всю анкету правильно.
