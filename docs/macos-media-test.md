# Первый тест Arni Code на Mac

Основной пользовательский стенд macOS: **MacBook Air с Apple M4**, архитектура **arm64 / Apple Silicon**. Используем его для регулярных проверок установки, интерфейса и медиа-сценариев. Наличие стенда подтверждено пользователем 16 октября 2026; первый пользовательский GUI/медиа-тест этой версии ещё не подтверждён. Нативные проверки CI выполняются отдельно и не означают проверку на этом Air.

Для MacBook Air M4 готов [установщик Arni Code 1.0.6 Apple Silicon](https://github.com/ssadkov/arni-code/releases/download/v1.0.6-skills-test/ArniCode-darwin-arm64.dmg) с профилями «Монтажёр», «Контент-редактор» и 11 навыками. Это [предварительный выпуск](https://github.com/ssadkov/arni-code/releases/tag/v1.0.6-skills-test). Приложение и DMG подписаны Developer ID и нотарифицированы Apple; ссылка на скачивание проверена без авторизации в GitHub. Python и FFmpeg устанавливаются отдельно с помощью агента, если отсутствуют. Первый тест установки зависимостей на чистом пользовательском M4 ещё предстоит. Выбор профессии и обновление навыков через F1 описаны в [инструкции библиотеки](profession-library.md).

1. Скачайте DMG для своего Mac: arm64 для M1/M2/M3/M4 и новее, x64 для Intel. Откройте DMG, перенесите Arni Code в Applications и запустите. Старое приложение предварительно закройте. Не отключайте Gatekeeper.
2. Войдите в свой аккаунт Arni. Для первого теста используйте бесплатный режим и модель Nemotron 3.5 Super VL free, если она доступна в текущем списке. Доступность и лимиты бесплатного провайдера могут меняться; платная модель для установки программ не нужна.
3. Откройте папку проекта. Для монтажа положите туда собственные source.mp4 (один человек на зелёном фоне) и background.jpg. Исходное видео обрабатывается локально; кадры, открытые агентом для оценки, передаются провайдеру выбранной модели. Используйте материалы, которые разрешено передавать этому провайдеру.
4. Создайте новый чат, выберите `/greenscreen-preview` из подсказки и вставьте запрос ниже. Если скилл не предлагается, проверьте версию приложения и отсутствие старой копии `.github/skills/greenscreen-preview` в проекте.

```text
Сначала проверь зависимости для greenscreen-preview.
Если Python 3 или FFmpeg отсутствуют, объясни, что нужно установить,
и помоги установить их; установку этих программ я разрешаю.
Если потребуется Homebrew или подтверждение macOS, объясни следующий шаг.
После успешной проверки сделай только пятисекундный горизонтальный
предпросмотр 1920x1080 из source.mp4 с фоном background.jpg и исходным звуком.
Выбери новую папку output/test-01; не перезаписывай существующие результаты.
Сам посмотри варианты и сравнительные кадры, проверь волосы, плечи и звук.
Допускается одна коррекция. Полный ролик не рендери, исходники не меняй.
Покажи файл, фактическое время рендера и оставшиеся дефекты.
```

Сначала можно проверить обычный чат или создание простого HTML-файла: для этого Python/FFmpeg не нужны. Для медиа тест считается успешным после открытия реального пятисекундного MP4 и проверки изображения/звука; одного сообщения агента об успехе недостаточно. Если установка не завершилась, сохраните текст ошибки, версию Arni, архитектуру Mac и вывод doctor (если Python уже работает).
