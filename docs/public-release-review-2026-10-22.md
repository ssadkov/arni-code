# Обсуждение первого публичного выпуска — 22 октября 2026

Статус: после согласования пользователя реализованы изменения интерфейса в ветке `codex/account-model-clarity`. Они подготовлены для локального тестового запуска Windows; новый установщик не выпускался. Backend, маршрутизация и ограничения публичного каталога в этой итерации не менялись. Исправление проверки контекста ниже пока остаётся отдельной задачей.

## Требование пользователя перед выпуском для внешних пользователей

- Ограничить каталог коротким списком проверенных моделей. Наличие модели в общем каталоге не считать подтверждением доступности или качества.
- Первый публичный выпуск: Amazon Bedrock и понятный баланс пользователя. OpenRouter и широкий экспериментальный каталог оставить за пределами обычного пользовательского сценария первого выпуска. Это требование к будущему выпуску, не выполненное переключение текущего продукта.
- Список должен ограничиваться сервером, а не только фильтром клиента. Проверять реальный источник, доступ аккаунта, цену, инструменты и изображения для заявленных сценариев.
- Показывать внутренний доступный баланс Arni понятными словами; не выдавать его за остаток средств в AWS. Уточнить до реализации, остаётся ли бесплатный лимит для публичного пользователя: баланс API и бесплатные шаги сейчас одновременно отображаются и запутывают.

## Согласованные изменения интерфейса

1. Исправить контраст аккаунта на светлой/тёмной теме и во всех состояниях, включая неактивное окно. Сейчас Arni summary добавлен поверх состояний аккаунта Copilot и наследует их оформление.
2. Убрать из обычного меню аккаунта Codebase Semantic Index. Это статус смыслового поиска Copilot, не условие чтения локальных файлов агентом. При необходимости показывать в расширенной диагностике проекта.
3. Для аккаунта Arni показывать нейтральный значок/аватар. GitHub оставить отдельным явным подключением к репозиториям, а не изображением входа через Яндекс/VK.
4. Скрыть Manage Copilot Models в обычном сценарии: текущая кнопка открывает управление с фильтром provider=Copilot, а не утверждённый каталог Arni.
5. Локализовать Settings как «Настройки», проверить остальные пользовательские строки/ошибки. Не предлагать пользователю менять язык ОС.
6. Источник модели задаёт backend для конкретной модели. Клиентская техническая группа OpenRouter сейчас объединяет модели разных источников; её название нельзя считать доказательством маршрута Bedrock/OpenRouter. Метаданные arni_provider есть, но источник не показан в названии. Для тестировщика полезны источник и фактический model ID в подробностях; при Amazon-only первом выпуске отдельный глобальный переключатель провайдера обычному пользователю не нужен.
7. В выборе специалиста показывать «Когда выбирать» и примеры. Разбор репозитория лендинга — Программист; исследование внешних источников — Исследователь; тексты — Контент-редактор. Произвольный текст в обычном Agent сейчас сам по себе не доказывает выбор подходящего специалиста.

### Реализовано и проверено

- Контраст подписи аккаунта исправлен тематическими цветами для светлого, тёмного и неактивного окна. В заголовке первым показан «Доступный баланс: $…», затем email; полный текст доступен при наведении.
- Доступный баланс — только положительный остаток включённого, не истёкшего внутреннего API-бюджета Arni. Приостановленный/истёкший бюджет показывает $0; состояние доступа и бесплатные шаги остаются в меню. Это не баланс счёта AWS.
- Скрыта панель диагностики Copilot с Semantic Index; значки аккаунта заменены нейтральными, кнопка Manage Copilot Models удалена из меню. Сохранены аватар пользователя, выход, настройки и история расходов.
- Локализованы меню аккаунта, названия разделов настройки агентов, уровни рассуждения, пустой список чатов и основные обёртки ошибок. Это не обещание полной локализации всех расширенных экранов IDE.
- В начале имени модели показано `AWS Bedrock` или `OpenRouter` по серверному `arni_provider`. По имени модели источник не угадывается; при отсутствующих метаданных ложная пометка AWS не добавляется. Идентификаторы, выбор по умолчанию и маршрутизация не менялись.
- У десяти профессий в выборе агента есть короткая строка «Когда выбрать». Общий Agent назван «Универсальный агент»; для разбора репозитория сайта рекомендован Программист.
- Проверки: 46 целевых Electron-тестов и 21 тест провайдера прошли; bundle расширения собран. CSS-проверка в Chrome дала контраст текста 11.90:1 на светлом и 11.06:1 на тёмном фоне, включая неактивное окно. Это проверка CSS на контрольных темах, а не испытание всех возможных пользовательских тем. Полная сборка установщика и полный набор тестов IDE не запускались.
- Для проверки использовать ярлык «Arni Code — новые агенты (тест)» после полного закрытия и повторного открытия тестового приложения. Обычный установленный Arni Code эти изменения пока не содержит.
