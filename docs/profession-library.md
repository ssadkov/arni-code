# Библиотека профессий и навыков — 1.0.6

Встроены два профиля: **Монтажёр** и **Контент-редактор**. Они используют выбранную пользователем модель: перехода на платную модель без выбора пользователя нет. Для оценки кадров нужна модель со зрением. Профиль задаёт порядок работы и набор навыков, но не гарантирует одинаковое качество решений разных моделей.

## Что входит

| Навык | Возможности первой версии |
| --- | --- |
| greenscreen-preview 1.0.2 | Замена зелёного фона, варианты ключа, короткий предпросмотр, сравнение волос и плеч |
| video-trim | Удаление выбранных интервалов, сборка оставшихся отрезков |
| video-audio | Выбор исходной/внешней дорожки, двухпроходная нормализация громкости, короткие сглаживания на стыках |
| video-screencast | Синхронная обрезка записи экрана, микрофона и отдельной камеры; неподвижная круглая или прямоугольная камера |
| video-subtitles | Локальная транскрибация через whisper.cpp с повторным использованием результата; SRT/VTT и вшитые субтитры |
| video-inserts | Неподвижные PNG/JPEG-вставки в заданные моменты результата |
| video-reframe | Явный кроп, размер, вписывание или заполнение; исходная ориентация сохраняется по умолчанию |
| video-story-edit | План смыслового сокращения с таймкодами и согласованием перед длинным экспортом |
| video-export-check | Декодирование, длительность, кадры, звук, SAR, таблица кадров и отчёт |
| content-editor | Редактура текста, структура, проверка утверждений, отдельные варианты для площадок, пакет для публикации |
| media-toolkit | Общий воспроизводимый Python/FFmpeg-помощник для перечисленных операций |

Новые навыки имеют версию 1.0.0, общий media-toolkit — 1.0.1 с совместимостью FFmpeg 8/9. CapCut не включён. Контент-редактор не публикует материалы автоматически и не получает личные контакты/правила автора из чужих проектов.

## Как пользоваться

1. После установки откройте **Customizations → Agents**: там доступны «Монтажёр» и «Контент-редактор». Выберите профиль для нового чата в переключателе агента; модель выбирается отдельно. Конкретный навык также вызывается через `/имя-навыка` в чате.
2. Для обновления инструкций нажмите **F1 → Арни: Обновить библиотеку навыков**. После загрузки нажмите «Перезагрузить окно» и создайте новый чат. В macOS палитра также открывается через Cmd+Shift+P; в Windows — Ctrl+Shift+P.
3. Для своего варианта: **F1 → Арни: Создать редактируемую копию навыков в проекте**, затем выберите папку проекта. Полный набор окажется в `.github/skills` и `.github/agents`, включая общий помощник. Откройте эту папку как проект и редактируйте файлы. Повторное копирование поверх существующих одноимённых папок запрещено.

Локальные навыки и профили с тем же именем имеют приоритет над общей библиотекой. Обновление с backend не меняет эти копии. Чтобы снова использовать общую версию, сначала сохраните свои правки и уберите соответствующую локальную копию из обнаруживаемой папки. Не переименовывайте русский `name` профиля, если хотите именно заменить исходный профиль, а не добавить второй.

Пример первого запроса Монтажёру:

```text
Проверь зависимости и используй готовые медиа-навыки.
Из source.mp4 оставь 0–2 и 4–7 секунды, сохрани исходную ориентацию и звук.
Сделай только пятисекундный предпросмотр в новой папке output/trim-01.
Посмотри кадры, проверь звук и длительность. Исходник не меняй.
Покажи файл, версию помощника, время рендера и оставшиеся дефекты.
Полный экспорт пока не делай.
```

## Обновления через backend

Один раз нужна новая версия приложения с загрузчиком. Дальнейшие изменения этой библиотеки не требуют переустановки Arni. Каталог публикуется по `GET /api/skills/library` с основным адресом `https://api.arnion.ru` и резервным `https://arni-backend.vercel.app`.

Обновление запускается явно пользователем. Клиент проверяет схему, разрешённые пути, размеры, SHA-256 каждого файла и ревизию всего каталога. Полная новая версия записывается в отдельную папку; указатель переключается после записи всех файлов. Открытое окно сохраняет прежние пути до перезагрузки, старые папки не удаляются. При ошибке сети остаётся установленная версия; при повреждённом кеше используются встроенные файлы.

Хеши защищают целостность, но не являются независимой подписью издателя: доверие основано на фиксированных HTTPS-адресах backend и явном обновлении. Скачивание не запускает Python-скрипты. Это первая общая библиотека, без магазина, платных подписок на профессии и корпоративных прав доступа.

Публикация: измените исходники в `src/vs/sessions/skills` / `src/vs/sessions/agents`, выполните `node scripts/export-skill-library.mjs <путь-к-backend>/src/lib/skills/library.json`, проверьте каталог и разверните backend. Список разрешённого набора общий для экспортёра, загрузчика и проверки пакета.

## Зависимости и ограничения

Python 3, FFmpeg/ffprobe и при необходимости whisper.cpp с локальной моделью устанавливаются на компьютере отдельно. Навык проверяет наличие и объясняет установку; без ранее данного разрешения агент запрашивает согласие на установку и загрузку модели. Для вшивания субтитров на Mac нужна сборка с libass: обычная Homebrew ffmpeg может её не содержать, поэтому используется ffmpeg-full по явному пути. Библиотека не содержит эти бинарные программы. Видео обрабатывается локально, но открытые агентом кадры передаются провайдеру выбранной модели.

Камера и звук должны начинаться синхронно с исходником: смещения не вычисляются. Камера/кроп неподвижны; вставки пока только картинки. Автоматическое удаление шума, музыка и генерация голоса не реализованы. Субтитры для вшивания задаются во времени готового ролика; пересекающие вырезанные интервалы исходные реплики нужно пересегментировать. Локальная ASR не исправляет смысл текста без проверки человеком.

Обычный edit ограничен 30 секундами; длинный экспорт требует `--full` и запроса пользователя. Новая папка результата обязательна. Отчёт о техническом успехе сохраняет `visual_review_required`: он не доказывает качество края, синхронизацию губ или субъективное качество звука. Измерение loudness в отчёте относится к первому проходу, а не к независимой проверке готового звука.

## Что проверено 16 октября 2026

- Реальный FFmpeg: совмещённые обрезка, вертикальное заполнение, круглая камера, PNG-вставка, кириллические субтитры, нормализация; проверены пиксели результата, длительность, кадры, звук, запрет перезаписи и сохранность исходника. Ошибочные планы отклоняются до рендера.
- На реальном исходнике создан отдельный трёхсекундный монтаж 1280×720 с сохранённым AAC-звуком; рендер 0.802 с, таблица кадров просмотрена. Это время помощника, не полный диалог и не API-стоимость. Прослушивание этого результата отдельно не подтверждено.
- Настоящий локальный whisper.cpp выполнил транскрибацию; повторный вызов использовал кеш. В ключ входят путь/размер/mtime исходника и модели, язык и версия движка; это не полный SHA-256 большого исходного видео.
- Тесты каталога проверяют подмену файла, неверные пути, атомарную смену версии, работу без сети, резервный адрес, приоритет и сохранность редактируемой копии.
- Настоящий SDK принял оба русских профиля и передал их инструкции локальному тестовому провайдеру. Платные запросы для этого не выполнялись.
- В изолированном окне Arni профили появились в Customizations, команда обновления загрузила настоящую библиотеку с backend. Команда редактируемой копии создала все 18 файлов; содержимое сверено с закреплённой ревизией каталога. Сбой нативного Windows copyfile/EBUSY устранён записью прочитанных файлов с запретом перезаписи. Тесты macOS в CI и первый пользовательский прогон на MacBook Air M4 — отдельные проверки; результат Windows не является проверкой GUI на Mac.
