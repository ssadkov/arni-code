# Первые сценарии шести специалистов

Статус: реализация в ветке `codex/sysadmin-computer-check`, draft PR #31; библиотека backend — draft PR #4. Это локальная тестовая версия, не новый опубликованный установщик. Первые сценарии имеют ограниченный объем: наличие профессии не означает поддержку любых задач этой области.

## Что добавлено

| Специалист | Навык | Первый результат | Проверка |
| --- | --- | --- | --- |
| Программист | app-development | Лендинг, калькулятор, исправление простой ошибки | Запуск, взаимодействия, скриншоты широкого и узкого экрана |
| Исследователь | source-research | Сравнение веб-источников или предоставленного текста/книги | Источники, места в тексте, дата, противоречия, неизвестное, фактический охват |
| Аналитик | spreadsheet-analysis | Просмотр CSV/XLSX, объединение, сверка по ключу и сумме | Дубли остаются неоднозначными, суммы Decimal, исходники не меняются |
| Дизайнер презентаций | presentation-design | Простой редактируемый PPTX и точечная замена текста в копии | Повторное открытие и структура; визуальная проверка отдельно при доступном рендере |
| Архивариус | file-organizing | План сортировки одной папки, подтвержденное применение и отмена по журналу | Коллизии/измененные файлы не перезаписываются; содержимое восстанавливается |
| Методист | lesson-design | Автономный HTML-урок с вопросами и объяснениями | Опора на исходный текст, верный/неверный ответ, повторная попытка, клавиатура |

Каждый профиль отвечает на «Что умеешь?» без запуска инструментов и не меняет выбранную модель автоматически. На главной карточка показывает исполнителя и выбирает его реальный профиль **после создания новой сессии, до первого сообщения**. Если профиль недоступен или выбор не применился, отправка прекращается с объяснением. Выбранная модель сохраняется. Старые ответы не переименовываются при смене специалиста.

Свободное поле создания приложения запускает Программиста. Другие задачи доступны через готовые карточки или выбор агента в обычном чате. Автоматический диспетчер произвольных задач в эту версию не входит. Первые шесть карточек видимы сразу; «Все идеи» раскрывает остальные, включая Сисадмина, Монтажёра, Секретаря и Контент-редактора.

## Зависимости и границы

- Браузер/терминал — инструменты приложения. Наличие модели само по себе не дает ей интернет и не подтверждает доступность браузерного инструмента в конкретной сессии.
- Python 3: помощники таблиц, PPTX, урока и сортировки. XLSX требует `openpyxl`; PPTX — `python-pptx`. При отсутствии специалист объясняет установку. Тестовые библиотеки разработчика устанавливаются изолированно, не считаются установленными у пользователя.
- Для визуального просмотра PPTX нужен доступный PowerPoint/LibreOffice или экспорт пользователя. Успешная запись PPTX не доказывает отсутствие наложений. Поддержка произвольных брендовых шаблонов и сложного rich-text редактирования не заявляется.
- Помощник таблиц не пересчитывает формулы, отказывает в сверке/объединении формульного ввода; нужны рассчитанные значения. Макросы, XLS и сохранение сложного исходного оформления не входят в первый сценарий.
- Архивариус работает с непосредственными файлами одной выбранной папки: до 500 записей, до 64 MiB на файл, без скрытых файлов/ссылок/вложенных папок/репозиториев. Перемещение копирует файл, проверяет хеш и удаляет старое расположение; отдельного удаления нет. Метаданные и ACL целиком не сохраняются. Пустые папки после отмены могут остаться. Прерванные/неоднозначные копии требуют разбора журнала.
- Помощник урока проверяет наличие текстовых опор, но смысловую правильность вопроса проверяет модель/пользователь. Ответы встроены в HTML: это самопроверка, не защищенный экзамен.
- Содержимое, которое агент читает инструментами, может попасть в выбранную LLM. Локальный помощник без сети не означает, что отчет/имена файлов/фрагменты таблицы не передаются модели. Для первых тестов используются только синтетические данные.

## Как подготовить независимые тесты

```text
python scripts/prepare-specialist-tests.py <новая-папка-вне-репозитория>
```

Генератор отказывает, если папка уже существует. Создает шесть проектов с учебными данными, TEST.md, копией конкретного профиля и его навыка. Не открывайте весь набор как один проект: откройте отдельную подпапку через «У меня уже есть папка с проектом», выберите специалиста и начните новый чат. Так тестовые данные и пользовательские копии навыка не смешиваются с инструкциями репозитория или другими профессиями.

На бесплатной модели проверьте $0 в выборе модели и фактическую стоимость по журналу. Не делайте платный резервный вызов автоматически. Затем можно повторить тот же тест на дешевой платной модели в новом чате. Наличие профиля не доказывает, что аккаунту доступна конкретная модель.

| Проект | Запрос | Основной критерий |
| --- | --- | --- |
| programmer | «Прочитай brief.md и сделай лендинг с калькулятором; проверь 1280/390 и сохрани скриншоты» | 3 × 2500 = 7500; отрицательные/пустые значения отклоняются |
| researcher | «Сравни три учебных источника в sources по цене, срокам и налогам» | Устаревшая цена и реклама не становятся текущим фактом; неизвестное явно отмечено |
| data-analyst | «Сверь invoices.csv и payments.csv по id и amount, дубли не угадывай» | Семь разных статусов, разница у 002 = −10; 001 остается строкой |
| presentation-designer | «Из report.md сделай шесть редактируемых слайдов для команды» | Только факты отчета; структура проверена; статус визуального рендера честный |
| file-organizer | «Подготовь только план сортировки inbox, покажи коллизии» | Ничего не перемещено до подтверждения; затем отдельно применить и отменить |
| instructional-designer | «Из material.md сделай HTML-урок с четырьмя вопросами» | Правильный/неправильный ответ, счет без накопления от повторных кликов, объяснения |

Второй раунд: Программист исправляет готовый калькулятор; Исследователь сравнивает реальные актуальные сайты с цитатами; Аналитик получает XLSX с формулой и должен сообщить ограничение; Дизайнер меняет один заголовок в копии; Архивариус отказывает в устаревшем плане; Методист добавляет вопрос с опорой на источник.

## Обратная связь и организация чатов

Обсуждать продукт и план реализации можно в одном общем чате. Для тестов — отдельный новый чат на специалиста и сценарий. После обновления инструкции повторять в новом чате: текущий может сохранять прежнюю библиотеку и историю. Для общего проекта специалисты могут работать последовательно, но фиксируйте задачу и результат передачи.

Шаблон: версия/commit, специалист, модель, запрос, ожидаемое, фактическое, время, стоимость по журналу, пути артефактов, скриншот/ошибка. Не считайте успешный тест Python-помощника доказательством успешного поведения LLM на всех этих задачах.

## Проверки разработчика

- `python scripts/test-specialists.py` с `openpyxl==3.1.5`, `python-pptx==1.0.2`: восемь тестов на данные, неоднозначности, неизменность исходников, PPTX, HTML escaping и план/применение/отмену файлов.
- `.github/workflows/test-specialists.yml`: те же проверки на Windows и macOS.
- Узкие Electron suites: StarterProjectGallery, StarterProfession, Arni skill library, Arni agent identity, agentHostAgentPicker и ModePicker — 27 тестов прошли локально.
- Навыки проходят skill-creator quick_validate. Backend JSON генерируется `scripts/export-skill-library.mjs`, проверяется клиентским parser/hash; содержит 20 навыков, 10 профилей, 42 файла.

Обновление библиотек через backend не заменяет обновление клиента для новых карточек/иконок. Локальные редактируемые копии и текущие чаты не перезаписываются.

При материализации профиля Agent Host может заменить путь к клиентскому файлу и использовать имя файла вместо русского названия. Клиент сохраняет известного специалиста только при однозначном сопоставлении с эффективным списком; несколько кандидатов не угадывает. Имена встроенных профессий в выборе отображаются на русском. Живой запрос карточки Исследователя на бесплатной Nemotron вызвал source-research и запросил сведения для сравнения. После исправления смены URI повторный запрос сохранил «Исследователь» в выборе после первого ответа; модель осталась бесплатной. Это проверка маршрутизации и начала сценария, а не полный тест всех профессий.
