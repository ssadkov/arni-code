# ArniCode 1.0.18

The AC mark on a dark background is the application icon for Windows, macOS,
and Linux. Windows setup artwork, Start tiles, application branding, and web
favicons use the same mark. Original brand assets are in
`resources/brand/ArniCode-Brand-Kit`.

The Windows installer uses a temporary short source path to handle nested
Copilot dependencies. CI checks that every application ICO image is embedded
in both the application executable and the installer.

This release follows the 1.0.17 model-picker test build. It also includes the
billing currency display and model-picker changes since stable 1.0.16.

Release validation uses the Windows and macOS workflows, package manifests,
native CLI checks, and SHA-256 checksums. macOS packages require Developer ID
signing and successful Apple notarization before stable publication.
