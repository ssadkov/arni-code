# Обновление 1.0.2: бесплатные и платные модели

## Зачем

Один аккаунт должен выбирать бесплатную vision-модель и платную модель непосредственно в приложении. Смена провайдера администратором больше не должна быть частью обычного сценария.

## Разбор теста Qwen3 VL

Чат `52fff3ed-ab5a-47fd-a9f0-783ea19d019e`, проект `C:/work/test_qwen_api`, 15 октября 2026, 23:03:55–23:08:10 Asia/Qyzylorda.

- 17 запросов модели, 16 действий PowerShell, 705184 входных и 1453 выходных токена.

- Агент не вызвал инструмент просмотра изображений; сохранение JPEG само по себе не означает визуальную проверку. Путал 0.5 с 5 секундами, предположил проблему кодека и сообщил неподтверждённое время.
- Первая команда `mkdir` получила таймаут 120 секунд. В fallback PowerShell код `$LASTEXITCODE` после cmdlet может быть пустым; такой маркер обработчик не распознавал.

## Изменения

- Backend объединяет разрешённые Bedrock-модели и OpenRouter; маршрут определяется выбранным ID, а не общей настройкой провайдера аккаунта. Сервер проверяет каталог и доступы.
- Бесплатные варианты проходят проверку нулевой цены, имеют отдельные бесплатные шаги и не занимают денежный резерв. Исчерпанный, отключённый или просроченный API-бюджет не блокирует их.
- PNG/JPEG доступны vision-моделям обоих провайдеров. Fallback бесплатной модели ограничен бесплатными кандидатами с поддержкой изображений, если запрос их содержит.
- Платные запросы сохраняют резервы и расчёт по фактическому USD cost OpenRouter. Для резерва учитываются опубликованные ценовые уровни и ставки image/cache; отсутствие точной стоимости помечается estimated.
- Кэш OpenRouter: сервер добавляет маркер стабильного текстового префикса только для документированных явных вариантов. Поле `cache_write_tokens` нормализуется в единый учёт. Для Bedrock Claude сохраняется прежняя реализация.
- В заголовке программы: email, API-бюджет и бесплатные шаги. В меню: тариф, состояние бюджета и расходы последнего активного чата. Тариф FREE и отдельно выданный бюджет отображаются раздельно.
- Модели показывают признаки оплаты, изображений и поддержки кэша. Признак кэша означает возможность, а реальное попадание подтверждается только счётчиками usage.
- Инструкции агента требуют реального просмотра кадров, проверки видеодорожки/числа кадров и воспроизводимого скрипта. FFmpeg следует вызывать с коротким диагностическим выводом; полный журнал остаётся в терминале/файле.
- PowerShell fallback выдаёт числовой sentinel и после cmdlet без LASTEXITCODE.

## Порядок испытаний

Каждый тест — новый чат в одном проекте, исходники неизменны, результаты в новой папке. Не продолжать старый неудачный чат Qwen: накопленная история исказит сравнение стоимости.

1. Бесплатные vision-модели: `google/gemma-4-31b-it:free`, `nvidia/nemotron-3.5-super-vl:free` (если остаются в текущем каталоге).
2. Дешёвые платные vision: `google/gemini-2.5-flash-lite`, затем Qwen3 VL через OpenRouter для сравнения с Bedrock.
3. Кэш: `anthropic/claude-haiku-4.5` для визуального цикла; `qwen/qwen3-coder-flash` для текстового кодинга. Проверять cache write первого и cache read последующего запроса, их стоимость и итог всей задачи.
4. Лендинг: одинаковое ТЗ, просмотр страницы на широком и узком экране, исправление по скриншотам.
5. Формы: тестовая форма, заполнение, проверка обязательных полей; финальная отправка только при соответствующем разрешении пользователя.
6. Простое приложение: одинаковая задача, запуск, сценарий пользователя и визуальная проверка.

Для видеотеста успешность: 5 секунд видеоряда, около 125 кадров при 25 fps, исходный звук, сохранённый человек, изменённый фон; просмотр кадров 0.5/2.5/4.5 с волосами и плечами. Код выхода 0 недостаточен.

Сравнивать качество, подтверждённые просмотры изображений, время всей задачи, число вызовов, токены/кэш и итоговый USD расход. Локальный рендер FFmpeg не является платным API-вызовом.
