# macOS 1.0.12: восстановление запуска движка агента

Причина ошибки `Native addon "cli-native" not found for darwin-arm64` в 1.0.6: `getCopilotRuntimePrebuildFiles` относил `prebuilds/*/cli-native.node` к необязательным файлам для всех платформ, кроме Windows. macOS CLI загружает этот модуль при старте, поэтому сессия не доходила до вызова модели или FFmpeg.

Исправление сохраняет модуль в пакетах darwin-arm64 и darwin-x64. Поведение фильтра Linux не меняется. Тест упаковки проверяет сохранение модуля для обеих архитектур, проверяющий скрипт требует непустые JS/native-файлы движка и пишет их SHA-256 в manifest.

Перед упаковкой ZIP/DMG workflow запускает настоящую CLI из подписанного/нотарифицированного `.app` через поставляемый Electron в режиме Node. SDK тестирует сессию, инструмент с изображением и завершение ответа через локальный HTTP-стенд. Пользовательские токены и платный провайдер не нужны. Эта проверка дополняет `code --version`, подпись, нотарификацию и медиатесты; она не заменяет пользовательский прогон GUI на MacBook Air M4.

Основа сборки — последний зафиксированный набор изменений `0a021fab`, включая десять профессий и двадцать навыков. Незакоммиченные изменения из других рабочих каталогов в выпуск не включаются. Версия повышена до 1.0.12; тестовый выпуск не меняет stable/latest.

## Проверка на Mac

1. Для Apple M1/M2/M3/M4 выберите `ArniCode-darwin-arm64.dmg`; для Intel — `ArniCode-darwin-x64.dmg`.
2. Закройте Arni Code, откройте DMG и замените приложение в `/Applications`. Папки проектов и профиль пользователя не удаляйте; обход Gatekeeper не требуется для успешно подписанного и нотарифицированного пакета.
3. Проверьте версию 1.0.12, войдите в Arni при необходимости, откройте папку с `source.mp4` и `background.jpg`.
4. Начните новый чат, выберите Монтажёра и доступную бесплатную модель с изображениями. Используйте `/greenscreen-preview` и попросите только пятисекундный предпросмотр, без полного рендера и изменения исходников.
5. Если Python/FFmpeg отсутствуют, навык должен объяснить необходимые зависимости. Это отдельный этап после успешного запуска движка. Материалы/кадры, читаемые моделью, передаются ее провайдеру.

Для обратной связи нужны версия/архитектура, выбранная модель, текст ошибки либо результат реального MP4, время и стоимость по журналам. Сам запуск движка не доказывает качество удаления зеленого фона.

В этом запуске отказал только шаг публикации arm64: GitHub вернул 403 служебному токену при создании выпуска.

Выпуск создан через авторизованный CLI. [39724974128](https://github.com/ssadkov/arni-code/actions/runs/39724974128) перенёс неизменённые финальные артефакты из CI после проверки успешных этапов агента/Apple, исходного коммита и SHA-256. SHA-256 DMG в CI и GitHub Release: `3f1e1aaa0f21ff752a098319167f61ec8f2868171bf1efb0595c4db3f242aa83`. Публичная ссылка проверена без авторизации (HTTP 200).

Для восстановления публикации workflow поддерживает `publish_ready_run`, `build_ref` с полным SHA, архитектуру и существующий release tag. Этот режим загружает готовые пакеты и не повторяет компиляцию или подпись. В тестовом запуске CLI нужны оба флага, как в рабочем окружении клиента: `ELECTRON_RUN_AS_NODE=1` и `COPILOT_CLI_RUN_AS_NODE=1`.

Intel в запуске 39722688234 прошёл проверку приложения Apple и тест упакованного агента. Финальная проверка DMG завершилась сетевым таймаутом App Store Connect; загрузка итогового CI-артефакта также получила таймауты GitHub. Проверенного публичного пакета x64 1.0.12 пока нет; выпуск arm64 завершён независимо.
