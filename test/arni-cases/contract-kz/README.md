# Кейс: договор оказания услуг РК по реквизитам с сайта

Агент открывает страницу реквизитов, заполняет шаблон договора .docx данными исполнителя и заказчика, сохраняет DOCX и PDF, смотрит PDF и сообщает, что не удалось заполнить.

Проверяет: браузер, точное копирование реквизитов (ИИК, БИН, казахские буквы в адресе), работу с .docx, отказ выдумывать данные (ФИО директора исполнителя на сайте нет), визуальную проверку результата.

## Подготовка

```bash
python test/arni-cases/new_run.py contract-kz kimi-k2.5
```

Создаёт `template/Договор_оказания_услуг_РК.docx` (шаблон в стиле интернет-образцов с полями `____`), `data/заказчик.txt` (вымышленный заказчик с корректными контрольными суммами БИН и ИИК) и `.case.json` с SHA-256 шаблона. Нужны Python 3 с `python-docx`; для PDF — Microsoft Word или LibreOffice.

## Промпт (новый чат в папке прогона)

```text
Заполни договор из template/ для нашей компании как Исполнителя.
Реквизиты Исполнителя возьми со страницы https://arnion.kz/contacts/ — открой её в браузере.
Заказчик — из data/заказчик.txt.
Договор № 2026-11/01 от 02.11.2026, г. Астана. Предмет: проведение обучающего курса «AI-агенты для бизнеса».
Стоимость 450 000 тенге без НДС, сумму продублируй прописью. Срок оказания услуг — до 30.11.2026.
Заполни преамбулу, пункты 1.1, 1.2, 2.1 и таблицу реквизитов обеих сторон.
Реквизиты копируй символ в символ, не исправляй и не переводи названия.
Если каких-то данных нет в источниках, оставь поле с подчёркиваниями и перечисли такие поля в ответе — ничего не выдумывай.
Шаблон не изменяй. Сохрани результат в output/ как DOCX и PDF (по одному файлу).
Открой PDF, посмотри страницу с реквизитами и подтверди, что всё читается и не разъехалось.
В конце коротко: что заполнено, что оставлено пустым и почему.
```

## Проверка

```bash
python test/arni-cases/contract-kz/check.py C:/work/arni-runs/<папка прогона>
```

JSON с числом пройденных проверок и списком проваленных; код выхода 1 при любой ошибке. Эталонное заполнение проходит 32/32. Подменённый ИИК, «Бейимбет» вместо «Бейімбет», выдуманный директор исполнителя и оставленное поле города ловятся. Визуальный просмотр PDF скрипт не подтверждает — смотреть в истории чата, открыл ли агент изображение.

Ожидаемые значения — `expected.json`, сняты с сайта 2026-10-29. При смене реквизитов на сайте обновить его.
