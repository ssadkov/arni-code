# Кейс: лендинг курса со скриншотами телефона и компьютера

Агент по брифу собирает одностраничный сайт курса, берёт контакты с arnion.kz, делает скриншоты 1440 px и 375 px, сам смотрит их и исправляет вёрстку.

Проверяет: работу с изображениями (скриншоты читает модель), браузер, дословный перенос фактов, адаптивную вёрстку. Шагов больше, чем в договоре, поэтому кейс подходит для сравнения моделей с кэшем (Haiku 4.5) и без него.

## Подготовка

```bash
python test/arni-cases/landing/build_project.py C:/work/test-arni-landing
```

Создаёт `brief.md` и `.case.json` с SHA-256 брифа.

## Промпт (новый чат, проект `C:/work/test-arni-landing`)

```text
Сделай одностраничный лендинг курса по brief.md.
Один файл output/index.html: стили внутри файла, без внешних скриптов, шрифтов и CDN — страница должна открываться без интернета.
Контакты, БИН и название организатора возьми со страницы https://arnion.kz/contacts/ — открой её в браузере.
Названия модулей программы перенеси дословно; даты, время, цену не меняй.
Кнопка «Записаться» — ссылка mailto на e-mail организатора, видна на первом экране и на телефоне, и на компьютере.
Открой страницу в браузере, сохрани скриншоты всей страницы: output/desktop.png при ширине 1440 и output/mobile.png при ширине 375.
Посмотри оба скриншота. Исправь, если что-то вылезает за край, мелко, налезает или плохо читается, и пересними. Не больше двух исправлений.
В конце коротко: что проверил на скриншотах, что исправил, что осталось.
```

## Проверка

```bash
node test/arni-cases/landing/check.mjs C:/work/test-arni-landing
```

24 проверки в настоящем Chromium (Playwright из `node_modules` репозитория):

- факты из брифа и с сайта;
- `mailto`;
- отсутствие внешних ресурсов;
- кнопка на первом экране на 1440 и 375;
- отсутствие горизонтальной прокрутки на телефоне;
- основной текст не меньше 14 px;
- ширина скриншотов.

Эталонная страница проходит 24/24. Обрезанный модуль, элемент шире экрана и отсутствующие скриншоты ловятся. Качество дизайна скрипт не оценивает — это смотрит человек. Просмотр скриншотов моделью подтверждается только историей чата: в запросах должны быть изображения.
