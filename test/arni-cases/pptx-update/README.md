# Кейс: обновить презентацию курса по брифу

Агент получает устаревшую презентацию .pptx и бриф с актуальными фактами. Он должен:
- исправить даты, цену, длительность, расписание и контакты (контакты — с arnion.kz);
- добавить слайд «Программа» в стиле колоды;
- отрисовать слайды в PNG, посмотреть их и исправить вёрстку.

Проверяет: правку чужого документа без поломки оформления, поиск всех устаревших фактов, а не только первого найденного, вставку слайда в нужное место, визуальную проверку по картинкам.

## Подготовка

```bash
python test/arni-cases/new_run.py pptx-update kimi-k2.5
```

Создаёт `source/Курс_AI-агенты.pptx` (5 слайдов, синяя полоса слева на каждом, шесть устаревших фактов), `brief.md` и `.case.json` с SHA-256 исходника.

Зависимости:
- Python 3 с `python-pptx`;
- для превью — Microsoft PowerPoint (экспорт слайдов через COM) или LibreOffice.

Ни то ни другое не входит в Arni. На машине без PowerPoint и LibreOffice агент не сможет посмотреть слайды и должен прямо об этом сказать.

## Промпт (новый чат в папке прогона)

```text
Обнови презентацию из source/ по brief.md.
Исправь все факты, которые противоречат брифу: дата старта, длительность, расписание, цена, контакты.
E-mail и телефон возьми со страницы https://arnion.kz/contacts/ — открой её в браузере.
Добавь слайд «Программа» сразу после слайда «Что вы получите»: четыре модуля из брифа дословно, в том же оформлении, что остальные слайды (синяя полоса слева, такой же заголовок и шрифт).
Исходник не изменяй. Сохрани результат одним файлом в output/.
Отрисуй каждый слайд в PNG в output/preview/ и посмотри все картинки. Если текст вылезает, налезает или выглядит не так, как на остальных слайдах, — исправь и перерисуй. Не больше двух исправлений.
В конце коротко: какие факты заменил, что проверил на картинках, что осталось.
```

## Проверка

```bash
python test/arni-cases/pptx-update/check.py C:/work/arni-runs/<папка прогона>
```

17 проверок:
- исходник не изменён;
- порядок шести заголовков;
- ни одного из шести устаревших фактов;
- новые дата, цена, длительность, расписание, e-mail и телефон;
- четыре модуля дословно и по порядку;
- синяя полоса на каждом слайде и позиция заголовка нового слайда;
- фигуры не выходят за слайд и текстовые блоки не наезжают друг на друга;
- текст не мельче 14 pt;
- PNG на каждый слайд.

Эталонное обновление проходит 17/17. Скрипт ловит: оставленную старую цену, слайд без полосы, блок шире слайда, наложение блоков, недостающее превью.

Переполнение текста внутри блока и общий вид скрипт не измеряет — это смотрит человек по `output/preview/`. Просмотр картинок моделью подтверждается историей чата.
